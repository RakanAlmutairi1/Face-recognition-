# 🔐 Face Recognition Access Control System
### Real-Time Unauthorized Entry Detection Using Deep Learning Facial Recognition

## 📖 Overview
This project is an AI-powered access control system that uses deep learning–based facial recognition to identify authorized individuals and detect unauthorized entry attempts in real time.

The system enhances physical security by replacing traditional access methods with an intelligent automated solution capable of recognizing faces, logging attendance, generating instant alerts, and supporting role-based access control.

---

## ✨ Features

- 🎥 Real-time face detection.
- 🧠 Deep learning facial recognition.
- ✅ Authorized user verification.
- 🚨 Unauthorized entry detection.
- 📱 Instant Telegram notifications.
- 🔒 AES-encrypted local database.
- 💾 Secure backup generation.
- 👥 Attendance logging.
- 🛡 Role-Based Access Control (RBAC).
